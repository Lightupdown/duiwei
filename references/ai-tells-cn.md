# 中文「AI 味」特征清单（v0.1）

> 这不是禁词表。每条标注处置等级和配额，按文体取用。
>
> 处置等级：
> - **禁用**：默认删掉，没有多少场景真的需要。
> - **配额**：可以用，但每千字 / 每分钟有上限，超了就换写法。
> - **情境**：只在特定条件下用（真有误解、真有社交对象、角色设定需要）。
> - **不误伤**：看起来像 AI，其实不该改。

---

## 一、词汇层

### 1.1 收条式应答（禁用）

把「我收到了你说的话」当成回应，信息没有向前走。

清单：这点我认 / 这点我同意 / 你说得对 / 你说得有道理 / 这句我先收下 / 我看到了 / 我明白了 / 懂了 / 收到 / 有道理 / 确实。

为什么像 AI：AI 被训练成先接住对方情绪、再输出内容；真人只在需要安抚或客套时用，而且不会一段连用两次。

改写方向：直接回应内容本身（复述一个具体点、补一个例子、提一个追问），或者把确认并进动作里。

- AI：这点我认。你说得对，效率确实比完美重要。
- 人：是，我上周就卡在「先做完再改」这步，改了三版反而更慢。

### 1.2 人设 / 网感标签词（配额：每段 ≤1，角色设定需要才用）

清单：我熟 / 先欠着 / 都归我管 / 这招挺阴 / 这波不亏 / 绷不住了 / 笑死 / 绝了 / 拿捏 / 省流 / 有一说一 / 不是哥们 / 给本小姐 / 哼 / 先这样 / 记我账上。

为什么像 AI：这些词辨识度高、模仿成本低，模型演「拽 / 有梗 / 傲娇」时最容易抓它们，最后变成口癖拼贴。真人用是因为当时真觉得好笑或真要怼人，密度低得多。

改写方向：换成具体描述或直接删；确实是人设台词就保留，但让口癖跟着情绪走，不要每句都挂。

### 1.3 通用连接词与评价词（配额：合计 ≤1/千字）

其实 / 说实话 / 说白了 / 讲真 / 老实说 / 确实 / 不可否认 / 某种程度上 / 从某种意义上说 / 值得注意的是 / 需要指出的是 / 归根结底 / 总而言之 / 与此同时 / 然而 / 此外 / 首先其次最后 / 综上。

注意：「其实」在口语里很常见，不是禁用；问题是 AI 每隔两句就用一次，拿它冒充口语。

### 1.4 职场黑话与万能升华（禁用）

赋能 / 抓手 / 闭环 / 颗粒度 / 底层逻辑 / 顶层设计 / 组合拳 / 护城河 / 生态位 / 长期主义 / 复利 / 认知升级 / 情绪价值 / 松弛感 / 内核稳定。

### 1.5 客服礼仪腔（熟人场景禁用）

希望对你有帮助 / 如有问题随时告诉我 / 感谢你的分享 / 很高兴为你解答 / 你的反馈很重要 / 祝你生活愉快。

文档、说明书里该有的礼貌照旧；聊天和口播里出现就是破绽。

### 1.6 名言撑场与四字格堆砌（作文 / 演讲高危）

- **名言**：正如古人所言 / 古人云 / 俗话说 / 常言道 / 有位名人说过 / 正如那句话所说。
- **四字格**：与时俱进 / 开拓创新 / 砥砺前行 / 不负韶华 / 持之以恒 / 常抓不懈 / 真抓实干 / 奋楫笃行 / 凝心聚力 / 守正创新 / 行稳致远 / 只争朝夕 / 久久为功。

处置：名言删掉，换成你亲眼看到的一个场景；四字格一次最多留一个，其余改成具体动作或大白话。

## 二、句式层

### 2.1 防御性「是 X，不是 Y」（默认禁用，除有明确触发）

模式：

- 不是 A，而是 B / 这不是 X，是 Y / 并非……而是……
- 与其说 A，不如说 B
- 表面上是 A，实际上是 B
- 我这么说不是为了 A，而是 B
- 看起来……其实……

人类用这些句式的条件：对方已经误会了要反驳，或者在澄清一个具体争议。AI 在没有触发时预防性辩解，是对齐训练里「防止误解、划清边界」留下的习惯。

改写：直接说 B。真需要澄清，先把 A 摆出来（引述对方或常见说法），再给 B，并且允许语气带情绪。

- AI：这不是效率问题，而是意愿问题。
- 人：效率？我觉得不是效率的事，就是不想干。
- AI：与其说这是技术问题，不如说是管理问题。
- 人：技术层面倒还好，麻烦的是没人拍板。

### 2.2 三连排比与对仗（配额：每篇 ≤1）

- 三个「是……」「让……」「从……到……」
- 开头对仗、结尾对仗、每段句式镜像
- 「既……又……」「不仅……而且……」成串

人确实会排比，但不会让整篇文字像歌词。

### 2.3 每段收一句金句 / 总结（配额：金句 ≤1/千字；口播 ≤1/2 分钟）

- 「说到底，……」　「这大概就是……」　「成年人的世界，……」　「你会发现，……」
- 段落最后一句突然变成能被截图的句子

改写：让一部分段落停在事实上，不升华；金句留给真正值得的那一句。

### 2.4 缩略命令句（情境：有真实社交关系才可用）

直接指出来 / 你先听我说 / 别问 / 记住 / 就这么办 / 先这样 / 你懂的。

问题不在短，在于零缓冲的命令式。真人要么加软化（要不你直接说 / 能不能具体点），要么加称呼和情绪（你说呗，我听着呢）。

- AI：哪句还像AI，直接指出来。
- 人：哪句还像 AI 啊？你直接说，我不玻璃心。
- 人（更软）：要是哪句还像 AI，你跟我说一声哈，我改。

### 2.5 说明文连接骨架（禁用）

首先 / 其次 / 最后、第一第二第三、接下来我们来看、下面从三个方面展开。

真人想到哪说到哪；真要列点，用「一个事儿是……另一个是……」。

### 2.6 书面腔 / 翻译腔（默认禁用，书面文案可少量保留）

- **进行＋动词**：进行优化 / 进行分析 / 进行了调整 → 直接说「改」「分析」「调了」。
- **随着……的发展 / 变化**：开头套话，删掉直接说事。
- **被……所……**：被动堆叠，改成主动句。
- **层叠的「的」**：对……的问题的分析。
- **四字格堆砌**：与时俱进、开拓创新、持之以恒、常抓不懈。
- **过长前置定语**：一个基于……的、面向……的、覆盖……的体系。

处置：口播里 0；书面文案只保留必要的术语，其余改成动词和短句。

### 2.7 段首零回指（语料验证 R=4.4，改写时补回指）

段落开头直接抛评价，不说在评价什么。真人说话默认对方知道话题，AI 更像「先给态度」。

- AI：说实话，很难。
- 人：说实话，这版方案很难落地。

体检脚本只能给「人工复核」提示，判不判由人定。

### 2.8 作文式升华套式（默认禁用，作文里最多一处）

- **时代腔开场**：在这个快节奏的时代 / 身处……的社会
- **递进升华**：是一种……，更是一种……；让我们……
- **对举铺垫**：看似……，却……；不是……而是……（见 2.1）
- **结尾金句**：后来我才明白 / 这大概就是成长的意义

处置：作文里改成具体场景或动作；升华一篇最多一处，而且要从细节里长出来，不能空降。

## 三、节奏与结构层（词表查不出来，但最容易露馅）

1. **句长均匀**：每句 15–25 字，句号密度稳定。真人句子忽长忽短，有 5 字短句，也有 60 字一逗到底。
2. **信息密度恒定**：每句都在推进观点，没有废话。真人会重复、绕回去、说一句没用的。
3. **没有停顿和改口**：真人说话有「那个……」「就是说……」「不对，我想想」。
4. **段落等长、总分总**：真人段落长短悬殊，有时一句成段，有时一大坨。
5. **标点过于规整**：分号、破折号、双引号、冒号全套齐活；聊天里句号滥用。
6. **从不跑题**：真人聊天会岔开一句再回来。
7. **给得太完整**：真人信息常残缺——时间记不清、名字想不起来、数字说个大概。
8. **细节有借有还**：AI 写下的道具，后面基本都会回收（纸→玻璃板、铜屑→铁盒、灯→灯不亮）；人的细节有两三成写了就丢。回收率过高就是设计。
9. **过度洁净**：全篇没有破折号、省略号、感叹号，问号 ≤1，句子都顺；干净过头也是签名。
10. **零阻力**：事件一次成功、不还价、没人怀疑、没有返工；太顺就是设计出来的。

## 四、语用层

1. **从不困惑、从不犯错**：AI 每句都确定；人会「我记得好像是……」「这个我不太确定」。
2. **情绪被标签化**：我直接笑死 / 绷不住了 / 血压上来了 / 给我整不会了。真人也有，但 AI 只有标签，没有身体反应和具体想法。
3. **金句密度过高**：每段都想让人转发。真人偶尔妙语，其余时候平庸。
4. **有问必答、面面俱到**：真人会说「这我真不知道」「你问别人吧」。
5. **态度永远得体**：真人会不耐烦、会偏袒、会说错话。

## 五、文体差异（阈值表）

| 文体 | 可以有的「人味」 | 不能有的 | 备注 |
| --- | --- | --- | --- |
| 视频口播 | 语气词、停顿、重复、改口、短句、闲话 | 长定语、书面连接词、完美对仗 | 呼吸节奏 > 文字修辞 |
| 书面文案（公众号 / 小红书 / 产品） | 具体细节、不均匀信息、克制的口语词 | 硬造错别字、每段口癖 | 口语是调料不是主食 |
| 微信聊天 / 评论 | 错别字、不完整句、表情、跑题 | 客服腔、成段说理 | 越短越像人，但别演 |
| 通知 / 公文 / 说明书 | 准确、克制、清楚 | 语气词、网络梗、强行口语 | 这类不需要「人味」，需要「人写的准确」 |
| 角色台词（二次元 / 搞笑人设） | 口癖、夸张、破音 | 每句都挂口癖、和情境无关 | 口癖跟着情绪走 |

## 六、不要误伤

- 专业术语、行业缩写在专业场景里不是 AI 味。
- 必要的总结、结论、分点在说明书 / 报告里该有。
- 角色设定需要的口癖是人物塑造，不是 AI 味。
- 正式文体的克制是得体，不是 AI 味。
- 排比、对仗在演讲稿里可以是修辞，只要不满篇。
- 公文格式、习惯用语（「现将有关事项通知如下」「以上通知，请认真贯彻执行」）、法规原文、准确数字都不是 AI 味，不能为了「像人」删掉。
- 对外公告把政策转译成生活场景、用「我们」，前提是信息准确；转译不是加梗或语气词。

## 八、中文语料验证特征（lieflat，283 万字对照研究）

来源：[lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)（MIT）。629 篇文章、约 283 万字、95,551 句；R = AI 侧频率 ÷ 人类侧。R≥2 纳入，1.25–2 条件纳入，0.8–1.25 排除。以下是通过检验的 11 项与需要标 [语料验证] 的结论。

| 特征 | R 值 | 说明 | 处置 |
|---|---|---|---|
| 引列表冒号 | **9.4** | 「主要包括：」「具体如下：」，冒号前那句只负责引出列表 | 禁用 |
| 拟人化喻体 | **7.3** | 「像一位智慧的导师」「不知疲倦的助手」 | 口播 0；书面 ≤1/篇 |
| 段首零回指 | **4.4** | 段落开头直接抛评价，不说评价什么；补个「这」就顺 | 改写时补回指 |
| 提示式冒号 | 3.8 | 「核心是：」「说白了：」 | ≤1/千字 |
| 对举结构 | 3.4 | 「不是 A 而是 B」 | 同 2.1，默认禁用 |
| 起首语 | 3.2 | 「说白了」「说实话」开头 | 同 1.3 配额 |
| 序数词小标题 | 3.1 | 一、二、三；第一、第二 | 0 |
| 破折号 | 3.0 | 组间极差百倍、各模型差异大，只作弱信号 | ≤2/千字 |
| 相邻句结构同构 | 2.0 | 连续几句同一句式 / 同一长度 | 打散 |
| 顿号并列过密 | 1.8 | 一句里多个顿号并列 | 单句 ≤3 个顿号 |
| 译文句式 | 2.6–5.3 | 「当……时」「对于……来说」「这意味着」「然而，」 | 0 |

**被推翻的流行说法（反向证据，不要照做）：**

- 正文设问 R=0.05：人类是 AI 的约 17 倍。**别删设问。**
- 比喻标记 R=0.42：人类约 2.4 倍。**别删比喻。**
- 口语连接词 R=0.26：人类更多。
- 单字虚词「就」R=0.45：人类约 2 倍多。**别删「就 / 其实 / 真的」这类节奏词。**
- 句长均匀度 R=0.87：作者后来复核，早期 51 倍是切分 bug，该项不成立。所以「句长均匀」只能当弱信号，不要单凭它判 AI。

**使用约定**：引用时标 `[语料验证]` 或 `[经验]`；语料以文章为主，口播场景要重新取样；模型风格会漂移，这份清单建议每半年回扫一次。

## 九、第二种 AI 味：表演式人味

模型被要求「口语化」之后，会批量生产一套「像人」的模板。它比书面腔更假，因为它在演人。

- **口癖成串**：这点我认、我熟、先欠着、我看到了、懂了。
- **防御性句式**：是 X，不是 Y；我这么说不是为了……
- **标语式短句**：直接指出来、别问、记住、就这么办。
- **伪互动**：你懂的、懂的都懂、评论区告诉我、你们说呢。
- **伪自曝**：我有个朋友、我之前也这样、说个真事（后面没有时间地点数字）。
- **金句密度过高**：每段都想让人截图。

判断标准：

- 口癖：每 500 字 ≤2 个；连续两句带口癖就删一个。
- 短句：念出来像海报或标语，就删。
- 伪自曝：没有具体时间、地点、数字、身体反应的「经历」，一律当编的。
- 真互动：对具体的人说具体的事，不靠「你们说呢」结尾。

## 十、作文特有 AI 腔（评分端视角）

依据：教育部教育考试院 2026 年解析（中国教育报 2026-06-08）、2025 年解析、河南中考 2026 阅卷要求、阅卷老师实测，详见 `research/deep/gaokao-essay.md`。

1. **以例代议**：观点 + 三个例子 + 「可见」，例子后没有自己的分析。判断：删掉例子，这段还剩自己的话吗？
2. **伪论据**：查无出处的「据说 / 有报道称 / 曾有一个团队」；AI 会编出听起来具体的新闻案例。用例必须说得出出处。
3. **视角错位**：人生导师口吻写中学生作文；议论拉回「我这个年龄能看到的」。
4. **一路正确**：没有误解、逃避、矛盾，结尾必「我终于明白了」。成长叙事要留一处「当时不懂 / 现在也没全懂」。
5. **伪风俗 / 伪行业知识**：为「生活气息」编作坊、行规、地方规矩；具体的前提是老实。
6. **文体杂糅**：先叙后议、夹叙夹议变夹生；前 100 字要能看出文体。
7. **素材撞车**：司马迁、苏轼、屈原、屠呦呦、爱迪生、居里夫人一篇出现两个以上要换。
8. **结构工整 ≠ 高分**：教育部考试院 2026 年明确「结构工整、辞藻华丽……可能流于平庸」；工整只保证二等。
9. **名言堆砌**：名句密度不是文采，「满满的全是名言」是负资产（2020 年《生活在树上》争议）。
10. **考场硬规则**：标题、字数、文体、点题句、卷面、真实信息——去 AI 味时不许动。

## 十一、报告 / 总结特有 AI 腔

依据：《党政机关公文处理工作条例》§8 报告文种、GB/T 9704-2012、政务文风调研（见 `research/deep/official-docs.md`、`gov-tone.md`），以及职场报告语料经验。

1. **万能开头**：「在公司的正确领导下，在各部门的大力支持下，我们紧紧围绕……」→ 删，直接给时间范围 + 结论。
2. **形容词成绩**：「工作效率显著提升，团队能力有效增强」→ 每个形容词后面找数字；找不到就删。
3. **问题虚化**：「仍存在一些不足，如创新意识有待加强」→ 现象 + 数据 + 原因 + 影响 + 责任。
4. **空表态**：「持续发力、久久为功、再创佳绩」→ 动作 + 责任人 + 时间 + 验收。
5. **下一步不可执行**：「进一步加强管理，不断提升服务水平」→ 写清谁、做什么、何时完成、交付什么。
6. **数据无口径**：「增长 30%」不说同比 / 环比、时间范围、来源 → 补口径。
7. **只报喜不报忧**：延期、超支、变更、离职、投诉、缺口不写 → 问题保留，报告才有判断价值。
8. **情况报告程序化**：「第一时间响应、举一反三」→ 事实、原因、责任、处置、整改时限。
9. **报告夹带请示**：「以上报告，请批准」→ 报告不夹带请示；要批复就另起「请示」。
10. **述职表功**：只写做了什么，不写职责、结果、不足 → 职责—动作—结果—不足—改进。

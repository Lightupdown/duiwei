# 02 · 公众号与文章

> 公众号长文、观点文、行业分析、知识分享、人物稿。目标是读者读完能记住一个判断、一个事实或一个人；把资料整理完只是副产品。

## 一、适用场景与目标

- 场景：公众号长文（1500–4000 字）、观点文、行业分析、知识分享、人物稿；知乎回答、专栏、newsletter 长文同理。
- 读者：会划走的人。前 300 字决定去留，所以开头直接进现场，不要先铺时代背景。
- 关系：一个写作者对一个具体的人说话。可以署名「我」，可以有自己的偏见。
- 目标：读完能复述一件事——一个场景、一个数字、一个跟主流不一样的说法，都算。
- 不负责：面面俱到。公众号最常见的毛病是信息很全，但没有一处是作者自己的。

**变体：官方评论 / 政论。** 党媒评论、时评、快评、人民论坛属于本档案的变体，排比、引用、金句、对仗密度明显高于个人公众号。改写时不能用通用配额（如三连排比 ≤1/篇）硬套，先按 `references/official-style.md` 的「四测试」判断：能对账、换题就不成立、在结构位置上、删了会疼——四条都中才保留。政治规范表述（中国式现代化、新质生产力、共同富裕、守正创新等）原样保留，不算四字格堆砌。

**通用底线（与任何文体冲突时排最前）**：不新增事实、数字、案例、第一人称经历；不改情态（「可能」不写成「确定」）；篇幅 ±20%；先删回执、金句、防御句式；保护区先标后改；看密度不看单次；原文干净就说不用改；别为了展示工作量硬改，别改过头。违反一条，重写。

## 二、人味标准

**允许**
- 书面为主。句子完整、标点规范；长句可以有，前提是跟短句交替出现。
- 个人经历、个人立场、一句明确的「我不同意」。作者态度是这类文章的资产。
- 一句闲笔、一句跑题、一处犹豫或自嘲。
- 一个段落只有一句话，下一段三百字；信息给得不均匀。
- 口语词做调料：每千字 3–5 个，「其实 / 就 / 说白了 / 我是说」分散出现。

**禁止**
- 客服腔：希望对你有帮助 / 欢迎留言讨论 / 感谢阅读。
- 每段末尾总结一句，每三百字升华一次。
- 伪互动：你怎么看？评论区聊聊。
- 「众所周知 / 研究表明 / 有专家指出」后面没有来源。
- 通篇句长 15–25 字，每段差不多长。

**密度配额（每千字）**：金句 ≤1（上限，非必填；0 句优先）；对举 0（除非原文在反驳一个具体说法）；提示式冒号 ≤1；引列表冒号 0；语气词 ≤1；破折号 ≤2；三连排比 ≤1/篇；拟人喻体 ≤1/篇。

## 三、AI 腔高危清单（按在公众号里露馅的程度排序）

1. **万能开场**：在当今…… / 随着……的发展 / 众所周知 / 这是一个……的时代 → 从一个具体时刻、动作、数字或一句对话进入：「上周三晚上十一点，我把那篇稿子删了第三遍。」**例外**：官方评论常用「新闻由头式开头」（最近……引发热议 / 前段时间收到一封读者来信），只要由头具体、跟论点直接相关，不算万能开场。
2. **伪数据与伪引用**：「研究表明」「数据显示」「一位从业十年的朋友说」→ 先看有没有实名来源：有单位、职务、姓名的引语保留；没有来源的按伪引用处理，给不出就删，或者老实写「这个我没找到公开数据」。
3. **每段「观点 + 例子 + 总结」**：例子讲完必补一句「这说明……」→ 例子讲完直接切下一个场景；判断放前面，或者不总结。
4. **三段式骨架**：首先 / 其次 / 最后；第一、第二、第三；小标题「一、二、三」→ 按读者的疑问顺序重排；小标题写内容名（「第一轮请专家」「第二轮自己讲」）。
5. **空泛金句收尾**：这才是……的本质 / 愿我们都能…… / 这大概就是…… → 结尾停在最后一个具体事实、动作或原话上。**例外**：政论允许动员式 / 回扣式结尾，条件是有全文事实支撑、回扣开头意象、只出现一次。
6. **假对话、假场景**：我曾经问过一位老师傅，他抿了口茶说…… → 没有时间、地点、名字、原话的「经历」按编造处理；有素材才写，原话照录。
7. **知识搬运腔**：所谓 X，本质上就是 Y / 简单来说，X 就是…… → 直接写机制：谁在什么时候做什么，卡在哪一步。
8. **段首零回指**：「说实话，很难。」没说评价的是什么 → 补回指：「说实话，这版方案很难落地。」[语料验证 R=4.4]
9. **对举与防御性辩解**：不是 A 而是 B / 与其说……不如说…… / 表面上看……其实…… → 直接说 B。真有人误解，先把对方说法引出来，再反驳。
10. **提示式冒号与列表冒号**：核心是： / 主要包括： / 具体如下： → 改成完整句子。冒号前面那句通常只负责引出列表。
11. **拟人化喻体**：像一位沉默的老师 / 无声地守护着这间教室 → 换成具体动作和数字。[语料验证 R=7.3]
12. **标题写成提问或行动指令**：如何……？ / 3 个方法让你…… / 为什么你总是…… → 标题写内容名：一个地方、一件事、一个判断，用名词短语；官方评论也可以用「动词短语 + 判断」式标题（如「把问题清单变成精彩答卷」），判据是标题有没有信息量，不机械要求名词短语。

## 四、保留清单（看起来像问题，但不能改）

- **作者立场**：偏激、有争议、跟主流相反都保留。「我认为这个方向是错的」不改成「这个方向仍有争议」。
- **真实案例与一手细节**：人名、地点、时间、数字、原话。被访者说话带的语气词、停顿是素材，不是杂质。
- **真实并列项**：三项都真就保留三项。宁可换句式，也不为避开三段式删信息。
- **行业术语与缩写**：首次出现必要时加一句解释，之后照用。别为了「好懂」把术语翻成大白话。
- **情态与不确定**：可能 / 据说 / 尚未确认 / 我记得，保留原文强度；原文没有的不补。
- **原文的好句子**：哪怕长、哪怕不符合本档案的节奏，是好句子就不动。
- **必要的小标题**：留，但检查它写的是内容名还是提问/口号。
- **作者语气习惯**：爱用括号、一句成段、自称「我」、爱用破折号，属于声音，不按 AI 味处理。
- **数据、图表、引用格式**：数字和来源格式原样保留。
- **规范性政治话语**：中国式现代化、新质生产力、十五五、共同富裕、守正创新等按规范提法原样保留，不算四字格堆砌；删改属于政治差错。
- **实名引用与专家职务**：「某某说」「某机构研究员表示」是可信度来源，不是借权威；引领导人讲话、政策原文要逐字准确，后文接落实动作或判断。

## 五、改写顺序与手法（按优先级）

1. **P0 冻结**：抄出所有数字、引文、案例、结论、立场，标「不动」。改完逐条对照。
2. **P1 标题**：改成名词短语（对象 + 动作/事件），删问句、数字承诺、行动指令。小标题同理。
3. **P2 结构**：找放大器段落——只把前面意思换个说法再说一遍的段，用「删掉它，论证有没有损失」测试。删每段末尾的总结句，拆「首先其次最后」，把最具体的场景或冲突提到开头。段落长短拉开，别每段一样重。
4. **P3 删**：万能开场、伪引用、假对话、客服腔、回执、空泛金句（能不留就不留，最多一处）。
5. **P4 句子**：拆对举，补段首回指，拆翻译腔（当……时 / 对于……来说 / 这意味着），把冒号列表句改成叙述，拟人喻体换成动作。
6. **P5 补**：补一个原文里就有的具体细节，给一处明确态度或犹豫，放一句闲笔。只能从原文或作者素材里取。
7. **P6 收**：金句最多 1，能删就删，结尾停在事实上，删 10%–20% 的「正确但没用」的句子，通读后复查事实。
8. **P7 报告**：三行内说改了什么、哪句是故意保留的、原文干净的地方有没有硬改。

## 六、AI → 人 对照（6 组）

> 说明：每组「改后」假定只使用原稿和作者已有的素材。实际改稿时，没有素材支撑的细节一律删掉，不补。

**第 1 组｜开头**
原稿：
> 在当今教育数字化转型的背景下，如何让技术真正服务于课堂，是每一所学校都必须面对的问题。我校 12 个班这学期安装了交互白板，其中 8 个班的使用记录为空。本文将从三个方面分析这一现象背后的原因。
改后：
> 这学期学校装了 12 块交互白板。期末查使用记录，8 个班是空的。用得最多的是投影，就是把电脑屏幕投上去。钱花了，课没怎么变。
动了什么：删「在当今……背景下」和「本文将从三个方面」两句导览；把原文的事实（12 个班、8 个空记录）提到最前；补一句作者判断（钱花了，课没变），它是原文「分析原因」立场的延续；不再预告结构。

**第 2 组｜中段论证**
原稿：
> 首先，培训内容要贴近一线需求。只有了解教师的真实痛点，培训才有针对性。其次，培训形式要多样化，单一的讲座容易让人疲惫。最后，培训后要有跟进机制，确保学以致用。综上所述，三管齐下，培训才能真正取得实效。
改后：
> 第一轮培训请的是省里的专家，讲得好，散了没人动。第二轮换成本校老师自己讲，讲的人自己先用上了。第三轮我们不再请人讲，改成每周三下午坐一起改教案，改完当周就上。内容、形式、跟进，一样都不能少，但顺序是反的：先有每周三那个固定动作，内容才有人听。
动了什么：拆「首先 / 其次 / 最后 / 综上所述」骨架；把三个抽象维度落成三轮具体做法；三项并列保留，没有删；删每句后面的总结；结论从「三管齐下」换成一个具体动作。

**第 3 组｜案例段**
原稿：
> 研究表明，及时的反馈对学习效果有显著影响。一位资深教师曾告诉我，学生最需要的不是批评，而是具体的建议。由此可见，反馈的质量远比数量重要。
改后：
> 作业发下去，学生只看分数。后来改成每道错题旁边写一句：这步为什么错，下一题先算什么。两个星期后，订正本上开始出现学生自己写的旁批。
动了什么：删「研究表明」和「一位资深教师曾告诉我」（给不出来源按伪引用处理）；把「反馈质量」这个结论换成可观察的机制：写在哪、写什么、多久见效；删「由此可见」。最后一句的效果描述要有真实素材，没有就停在机制那一步。

**第 4 组｜转折**
原稿：
> 当然，技术并非万能。与其说问题出在工具上，不如说出在人的意愿上。我们不能只看到技术带来的便利，也要警惕随之而来的风险。
改后：
> 白板装好那天，老师们拍了照发朋友圈。两个月后，三楼柜子里锁着四台。备课做一页课件多花四十分钟，多数人试过一次就算了。评优只看分数，谁愿意花时间学新东西。
动了什么：删「当然」「并非万能」「与其说……不如说」；把「意愿」落成成本账（四十分钟）和一个制度原因（评优），判断有了落点；结尾停在事实上，不喊口号。

**第 5 组｜结尾**
原稿：
> 教育的本质，是一棵树摇动另一棵树。愿每一位教育者都能守住初心，在平凡的岗位上发光发热。这，就是这次实践留给我们最宝贵的启示。
改后：
> 学期末统计，27 份改过的教案里有 9 份用到了下学期。剩下的还在共享文件夹里。下学期，周三下午继续空出来，不请人讲，就坐着改。
动了什么：删「教育的本质」「愿」和「这，就是……启示」三处升华；换成可核对的数量、位置和下一步安排；结尾停在一个具体动作上。

**第 6 组｜标题**
原稿：
> 如何让教师培训真正落地？3 个关键步骤帮你少走弯路
改后：
> 每周三下午改教案：一所县中教师培训的三轮调整
动了什么：从提问加数字承诺改成「对象 + 事件」的名词短语；删「3 个关键步骤」「少走弯路」；小标题跟着改——「一、为什么要改？二、怎么改？三、效果如何？」改成「第一轮请专家」「第二轮自己讲」「第三轮坐一起改教案」。

## 七、交付前自检（逐条回答是/否）

1. 标题是名词短语吗？有没有问句、「3 个方法」「如何」？
2. 开头第一段有一个具体时间、地点、动作或数字吗？有没有从「在当今」「随着」起步？
3. 出现「研究表明 / 数据显示 / 专家指出」的地方，都给得出来源吗？
4. 每个段落最后一句是总结吗？删掉以后段落还成立吗？
5. 有没有「首先 / 其次 / 最后」「第一、第二、第三」？真需要清单才留。
6. 全文金句是否超过 1？有没有把「留一句金句」当成任务？0 句时结尾是否仍然成立？
7. 有没有「不是 A 而是 B」「与其说……不如说」？有明确的反驳对象才能留。
8. 每个案例有一手细节（谁、什么时候、具体动作）吗？没有细节的「经历」按编造处理了吗？
9. 段首有没有直接抛评价、没说在评价什么？
10. 事实、数字、引文、立场、情态和原文一致吗？篇幅在 ±20% 内吗？原文干净的地方没硬改吗？

## 八、与相邻文体的边界

- **作文 vs 公众号**：作文要书面、要审美，可以有个人化节奏，但不加口语连接词；公众号可以有「我」、有立场、有一句口语。两边都不该写成口播。
- **公众号 vs 短视频口播**：口播一行一个气口、句子短、设问多、有称呼；公众号可以有长句、小标题和完整结构。口播稿直接搬进公众号会松，公众号稿拿去念会喘不上气。
- **公众号 vs 通知公告**：公告要准确克制，只删套话，不加个人立场；公众号有立场是资产，公告里有立场是事故。
- **公众号 vs 小红书**：短段、表情、话题标签是小红书的文体，不算 AI 味；公众号删掉标签表情也不算改进。判断标准是这个渠道默认长什么样。
- **文章 vs 人物稿**：人物稿里被访者的话可以原样保留口语、停顿、方言词，这是素材，不是需要清理的杂质。
- 一个判据：读者是来读「一个人想清楚某件事」，还是来「查一份资料」？前者进本档案，后者不进。

# 朋友圈与聊天：去 AI 腔档案

## 一、适用场景与目标

- 朋友圈：个人动态、活动宣传、工作转发、节日和纪念日。
- 微信私聊：约时间、问事、拒绝、求帮忙、道歉、报平安。
- 群消息：班级群、工作群、亲友群里的回复与闲聊。
- 评论区短回复：朋友圈评论、公众号留言、视频号评论。

目标：短、随意、不演。读起来像这个人在那个时刻随手打的，不像客服、不像公关稿、不像 AI 代写。收信的人一眼能看出要回什么、要不要回。

这类文体的核心是省。能一个字说清，不用说一句。朋友圈一条只写一个瞬间，聊天一条只讲一个意思。

## 二、人味标准

允许：不完整句；省主语；省标点，用空格或换行断句；语气词；表情；适度错别字（原文有才留）；拆条发；补一句；改口（「算了」「当我没说」）；方言；个人口癖；跑题；直接拒绝；敷衍（「嗯」「行」）；语音转文字的停顿。

禁止：客服腔；成段说理；书面连接词；完整主谓宾排比；伪互动（懂的都懂、你们说呢）；伪自曝（没有时间地点数字的「我有个朋友」）；群发式祝福；营销体；每句挂口癖；装可爱或装拽；emoji 堆砌；硬造错别字；给聊天加称呼和落款；给朋友圈加小标题。

口语词容忍度：最高。语气词、表情、方言都能用。但「短」不等于「冷」，「随意」不等于「用力」。判断标准：这条发给熟人，对方会不会觉得「你今天说话怎么怪怪的」。

**保真底线（优先于一切文风判断）：** 不新增事实、数字、案例、第一人称经历；不改情态；篇幅 ±20%；先删回执、金句、防御句式；保护区（口癖、方言、真实语气、必要的时间地点）不动；看密度不看单次；原文干净就直说不用改；别改过头。聊天里的「编细节」最容易被发现：不知道当时雨多大，就别写「雨大得像倒下来」。

## 三、AI 腔高危清单（按该文体排序）

1. **客服腔开场与收尾。**「感谢邀请」「非常重视」「期待您的回复」「希望对你有帮助」「祝生活愉快」→ 删。开场直接说事，收尾停在事上。
2. **每句都是完整句加句号。**「好的。我明天上午过去。」→「好 明早过去」。聊天里的句号带语气，别乱加。
3. **书面连接词。**「然而」「此外」「因此」「首先」「总的来说」「与此同时」→ 删，用「然后」「反正」「不然」「所以」。
4. **礼貌模板成段。**「请问你周六下午是否有空？如果方便的话……如果不方便的话……」→「周六下午有空吗」。一个问句给一个方案，别给协商流程。
5. **情绪标签代替具体。**「今天真的超级开心！」→ 给具体的：走了两万步、腿废了、猫占着沙发。
6. **伪互动与空问句。**「懂的都懂」「你们说呢」「评论区告诉我」「求攻略」「在线等」→ 对具体的人说具体的事，或者不说。
7. **伪自曝。**「我有个朋友也遇到过」「说个真事」，后面没有时间地点数字 → 按编的删掉。
8. **群发式祝福。**「祝大家中秋快乐，阖家幸福，万事如意」→ 短，或者具体到人和事：谁的月饼、放在哪。
9. **营销体发圈。**「感恩遇见」「记录美好生活」「今日份的快乐」「生活需要仪式感」「被治愈了」→ 写具体的那件事，别给生活贴标签。
10. **防御式解释、排比、升华收尾。**「我这么说没有别的意思，只是……」/「一半是烟火，一半是清欢」/「生活总会奖励认真的人」→ 删。拒绝给一句真理由加一个动作，朋友圈停在最后一个具体事实上。

## 四、保留清单（看着像问题，其实不能改）

- **个人口癖和固定说法**：「好滴」「行」「嗯嗯」「我去」「那我走了」。同一个人反复用的那几个词，是他的声音。
- **方言和地域表达**：「巴适」「中」「整」「咩」「唔该」「得劲」。
- **真实语气**：敷衍、火气、撒娇、阴阳怪气、懒得回。「嗯。」就是冷淡，别加感叹号改成「嗯！」。
- **打字痕迹**：原文已有的错别字、漏字、重复发送、没发完的半句。别修得太干净，也别新造。
- **语气词和表情**：看关系，一个就够。
- **「在吗」「忙吗」**：熟人之间真实存在，别改成「您好，请问现在方便吗」这种更假的。
- **必要信息**：时间、地点、地址、门牌、金额、航班号、房间号、集合点。为了短删掉这些是不合格。
- **对方的原话**：回复时先接住具体那句，别笼统回「收到」。
- **朋友圈的定位、照片、具体名词**。
- **群里的 @ 和引用回复**。
- **一两个字**：「行」「去」「好」都是完整的回复。

## 五、改写顺序与手法

1. **定关系与场合。** 跟谁、什么关系、公开还是私聊、要不要留证据。同样一句「不行」，对同事和对朋友写法不同。
2. **圈保护区。** 时间、地点、金额、对方原话、语气、口癖、方言先标出来，改的时候不动。
3. **删客套。** 开头结尾的礼貌模板先删干净，剩下的才是内容。
4. **拆条、省主语。** 一段话拆成 1–3 条短消息，每条一个意思；「我觉得这地方行」→「这地方行」；朋友圈一条只写一个瞬间。
5. **换具体。** 情绪标签换成动作、物件、身体反应。原文没有的具体细节不能编，先从用户给过的素材里找。
6. **处理邀约和拒绝。** 邀约给「结论 + 时间地点」；拒绝给「结论 + 一句真理由 + 一个补偿动作」。
7. **剪结尾。** 不祝福、不总结、不追加「期待回复」「祝生活愉快」。
8. **反向查表演，再对事实。** 口癖每 500 字 ≤2 个；没有硬造错别字；表情不是堆的；时间、地点、金额、情态核对一遍。聊天里最常被删丢的是「几点」和「在哪」。

## 六、AI → 人 对照（6 组）

> 改后的事实来自原稿或发布人给过的素材。事实里没有的细节不编；例子里出现的具体细节，视为发布人事先交代过。实际改写时没有就问。

**例 1 朋友圈个人分享（搬家）**
```
【原稿】
今天的心情真的超级好！生活总会在不经意间给我们惊喜，感谢每一个认真生活的自己。
搬进新家，收拾得差不多了，阳光照进客厅的那一刻，觉得一切都是值得的。愿我们都能在平凡的日子里，找到属于自己的小确幸。
【改后】
搬完了 腰疼
客厅下午有太阳 箱子还有一半没拆
明天再说吧
```
动了什么：删「心情超级好/感谢自己/一切都是值得的/愿我们」这一套总结；情绪换成身体反应和没干完的事；「明天再说吧」留个懒劲，比「小确幸」像人。一条朋友圈只交代一个瞬间，不负责给生活下结论。

**例 2 朋友圈活动宣传（书店读书会）**
```
【原稿】
在这个快节奏的时代，我们依然相信阅读的力量。本周六15:00，城市书店将举办读书分享会，共读《XXX》前两章。座位有限，先到先得。期待与您在书香中相遇。
【改后】
周六下午三点 读书会
《XXX》前两章
城市书店 椅子不多 先到先坐
```
动了什么：删时代背景、抒情句、「期待与您在书香中相遇」；「15:00」改成「下午三点」，朋友不用换算；三行三个信息，一眼看完。活动文案停在信息上，比加一句期待可信。

**例 3 私聊约时间**
```
【原稿】
你好，请问你这周六下午方便吗？如果方便的话，我们想约你周六下午三点一起去看XX美术馆的展览。如果不方便的话，我们可以再另约时间。期待你的回复，谢谢！
【改后】
周六下午有空吗
XX美术馆 三点
门口见
```
动了什么：拆三条，删「你好/请问/如果……的话/期待回复/谢谢」；一个问句只给一个方案，不给两套备选；时间地点从从句里拎出来单独一行。约人的核心是让对方回答「行」或「不行」。

**例 4 私聊拒绝**
```
【原稿】
非常感谢你的邀请！我认真地考虑了一下，因为这周六已经有了其他的安排，所以可能没办法参加这次活动了，非常抱歉。希望下次还有机会一起，下次换我来组织。祝你们玩得开心！
【改后】
周六那天有事，去不了
抱歉啊
下次我来组
```
动了什么：删「非常感谢」「我认真地考虑了一下」「可能没办法」「希望下次还有机会」；结论提前，理由具体到「周六那天」；补偿动作单独一句。「可能没办法」是留余地，真实拒绝反而说得干脆。关系近的，「抱歉啊」一句就够，不用写三段。

**例 5 群消息回复（问进度）**
```
【原稿】
感谢提醒。关于PPT的修改，我已经在跟进处理中，预计今天18:00前完成并上传至群文件，请各位耐心等待。如有其他问题欢迎随时沟通。
【改后】
在改 18点前传群文件
```
动了什么：一句话能说完；「感谢提醒/已经在跟进处理中/请耐心等待/欢迎随时沟通」全删；承诺的时间（18:00）原样保留。群回复的功能是让问的人放心，「在弄 + 时间」就够。

**例 6 评论回复（朋友发旅行照）**
```
【原稿】
照片拍得真好看！风景太美了，感觉你玩得很开心，好羡慕！下次我也想去，求攻略～
【改后】
哪儿拍的 我也想去
```
动了什么：删「拍得真好看/风景太美/感觉你玩得很开心/羡慕」一串评价，对方知道照片好看；「求攻略」换成一个具体问题，才有得聊。评论越短越像随手点开写的。

## 七、交付前自检（逐条回答是/否）

1. 这条发给熟人，对方会觉得「你今天说话怎么怪怪的」吗？
2. 有没有一句客服训练出来的礼貌话？
3. 有没有成段说理、总结、升华？
4. 能不能再删一半字，意思不变？
5. 有没有一处具体的东西（时间、地点、物件、身体反应）？
6. 时间、地点、金额这些必要信息还在吗？
7. 有没有「懂的都懂」「你们说呢」「求攻略」这类伪互动或空问句？
8. 有没有为了像人硬造错别字、堆表情、成串口癖？
9. 邀约给了一个具体方案吗？拒绝够干脆、有理由有补偿动作吗？

## 八、与相邻文体的边界

- **朋友圈 vs 公众号**：朋友圈几十字、一个瞬间、可以不配字；公众号几百字、一个观点、要结构。把公众号段落发朋友圈像发传单，把朋友圈文案扩成推文没人看。
- **朋友圈 vs 聊天**：朋友圈是广播，不对「你」说话；要对谁说话就私聊。
- **聊天 vs 邮件**：邮件要称呼、要落款、可以成段、要留档；聊天是即时对话，对方在等回答，不要写「综上所述」。
- **聊天 vs 口播**：口播说给一群人听，允许气口、设问、重复；聊天对着一个人，允许不完整、敷衍、改口。把口播稿发进群里会很怪。
- **群消息 vs 通知公告**：群公告是通知体，发群里也要有时间、地点、谁做什么，不能加「哈」「~」；普通群聊不用。
- **评论区 vs 私聊**：评论区公开，短、别自曝隐私、别写长；私聊可以多问两句。

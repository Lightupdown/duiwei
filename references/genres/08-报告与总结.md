# 报告与总结：去 AI 腔档案 08

适用文本：法定公文里的「报告」、工作总结、年度 / 季度总结、项目报告与复盘、调研报告、情况 / 事故报告、述职报告、周报月报、汇报材料。

这类文本的「人味」不是口语，也不是文采，是**可信**：数据有口径，成绩不拔高，问题不虚化，下一步能执行。AI 腔在报告里比在聊天里更耽误事——领导照着它做判断。

## 一、适用场景与目标

- **法定公文报告**：向上级机关汇报工作、反映情况、回复询问。依据《党政机关公文处理工作条例》§8。文种是「报告」，结语「特此报告」；**报告不得夹带请示事项**。
- **工作总结 / 年度总结 / 季度总结**：面向单位内部，重复盘、数据、问题、方法。
- **项目报告 / 复盘报告**：目标、过程、结果、偏差、经验、下一步。
- **调研报告**：背景、方法、样本、发现、建议；方法不写清，结论就没有分量。
- **情况报告 / 事故报告 / 通报**：事实（何时何地何后果）→ 原因 → 责任 → 处置 → 整改。
- **述职报告**：职责是什么、做了什么、结果如何、哪里不足、怎么改。评价对象是自己，不是单位。
- **周报 / 月报 / 汇报材料**：进度、阻塞、需协调事项、下一步；「本周完成」本身不是 AI 味，空话才是。

目标：读者在最短时间里知道**结果、问题、下一步**；数字能对上，责任能落地。

**数据与口径检查（本类专属，不能拿去套叙事文）**：每个数字有没有时间范围、同比 / 环比口径、来源、样本量？有没有把估算写成确定、把推测写成原因？这一条从 `review-layers.md` 的 L2 移到这里。

## 二、人味标准

**允许：**

- 数据、口径、时间范围、来源；同比 / 环比 / 截至日期写清楚。
- 具体问题、风险、偏差、失败；原因分析可以指向自己。
- 克制的评价：用事实带出判断，不喊口号。
- 结论先行、分点、表格、编号；结构清楚是报告的本分。
- 法规、文件、合同、术语原文；正式称谓。

**禁止：**

- 口语词、语气词、网络梗、表情；报告不玩亲切。
- 空泛成绩：显著提升 / 有效改善 / 全面增强 / 大幅提高（后面没有数字）。
- 拔高：里程碑 / 新台阶 / 新高度 / 历史性突破。
- 空表态：持续发力 / 久久为功 / 再创佳绩 / 狠抓落实 / 扎实推进。
- 虚化问题：仍存在一些不足 / 有待进一步加强 / 仍有提升空间。
- 下一步不可执行：进一步加强 / 不断提升 / 持续优化（没有动作、责任人、时间）。
- 数据无口径、样本不交代、把估算写成确定。
- 述职写成表功；情况报告只写「立即响应、举一反三」不写事实。
- 报告夹带请示；一文多事、文种混用。

**口语词容忍度**：0。修辞密度：几乎为 0，最多一处且有事实支撑。金句：0。

## 三、AI 腔高危清单（按报告里出现的频率）

1. **万能开头**。「在公司的正确领导下，在各部门的大力支持下，我们紧紧围绕……」→ 直接给时间范围 + 一句结论：「1—6 月部门完成 37 个项目，同比多 9 个。」
2. **形容词堆成绩**。「工作效率显著提升，团队能力有效增强。」→ 「平均交付周期从 24 天降到 19 天；12 名新同事培训后测试均分从 62 提到 78。」
3. **三段式模板**。成绩—问题—展望，问题永远只有一句「仍存在不足」。→ 问题单列，写现象 + 数据 + 原因 + 影响。
4. **拔高**。「这是部门发展史上的重要里程碑。」→ 删；把结果和对比留下。
5. **空表态**。「下一步将持续发力、久久为功，再创佳绩。」→ 「8 月底前把验收模板发到各组，负责人逐项确认。」
6. **下一步不可执行**。「进一步加强管理，不断提升服务水平。」→ 动作 + 责任人 + 时间 + 验收标准。
7. **数据无口径**。「业绩增长 30%。」→ 「上半年营收同比增长 30%（去年同期 420 万，今年 546 万，财务口径）。」
8. **只报喜不报忧**。「项目整体推进顺利。」→ 写清延期、超支、变更、人手缺口，以及影响。
9. **述职写成表功**。只列自己做了多少事，不写职责、结果、不足。→ 职责—动作—结果—不足—改进，各一段。
10. **情况报告程序化**。「第一时间响应、举一反三。」→ 事实、原因、责任、处置、整改，按时间线写。
11. **调研报告没有方法**。直接给结论，不写样本和方法。→ 样本量、抽样方式、时间、局限，放在发现之前。
12. **报告夹带请示**。「以上报告，请批准。」→ 报告不夹带请示；需要审批就另起「请示」，用「妥否，请批示」。

## 四、保留清单（看着像问题，其实不能改）

- **数据与口径**：数字、时间范围、同比 / 环比、来源、样本量。一个字不能改；口径不清就标缺，不猜。
- **问题、风险、偏差原文**：尤其是对己方不利的部分。删掉问题，报告就失去价值。
- **责任主体与时间节点**：谁负责、什么时候完成、交付什么。
- **法定格式与文种**（[公文惯例]）：标题（发文机关 + 事由 + 文种）、主送机关、发文字号、成文日期、附件说明；报告结语「特此报告」。
- **法规、政策、合同、术语原文**：条款、文件名、文号、定义原样保留。
- **真实成绩**：可以压缩表达，但不能为了「不吹」把真成绩删掉；只是不拔高。
- **事实 / 判断 / 建议的区分**：哪句是事实、哪句是推测、哪句是建议，不能混成一句。
- **涉密与隐私**：脱敏（人名、客户、金额），不是整段删除。
- **单位固定模板与上级要求**：格式、栏目、报送对象、时限；这些不是 AI 味。

## 五、改写顺序与手法

0. **定类型与读者**：法定报告 / 工作总结 / 述职 / 调研 / 情况报告 / 周报？给上级、给同事，还是给自己？类型错，后面全错。
1. **冻结数据与口径**：先抽一张数据表：数字、时间范围、同比 / 环比、来源、样本量。缺的标「待补」，不编。
2. **结论先行**：报告类第一段给结果或判断；述职按职责顺序；情况报告按时间线。
3. **形容词换事实**：每个「显著 / 有效 / 大幅」后面找数字；找不到就删，不许留。
4. **问题具体化**：现象 + 数据 + 原因 + 影响 + 责任，能指向自己的不要推给「客观原因」。
5. **下一步可执行**：动作 + 责任人 + 时间 + 验收 / 交付物；写不出的下一步就是空话。
6. **删套话与拔高**：万能开头、空表态、里程碑、口号；删完读一遍，信息有没有少。
7. **格式与文种**：标题、主送、结语；报告不夹带请示；该脱敏的脱敏。
8. **保真校验 + 冷读 + 自检**：数字、口径、责任、时限逐条对原文；以领导视角问「看完我知道什么、要做什么」。

## 六、AI → 人 对照（6 组，含占位版与素材版）

> **示例规则**：本节里的数字、时间、人名都是演示素材，不是原稿事实。真实改写分两种：
>
> - **用户没给数据**：改后保留 `【待补：项目数 / 同比 / 原因 / 时间…】`，不能编。
> - **用户给了数据**：按素材填，并在交付说明里注明来源。
>
> 照抄示例数字 = 编造。例 1、2 同时给「无素材占位版」和「有素材演示版」；例 3–6 给占位版，有素材时把占位替换成用户给的事实。

**例 1 工作总结开头**

- **原稿**：在公司的正确领导下，在各部门的大力支持下，我部门紧紧围绕年度工作目标，扎实推进各项重点任务，取得了显著成效。现将上半年工作总结如下。
- **改后（无素材，占位版）**：1—6 月，部门完成【待补：项目数】个项目，平均交付周期【待补：起始—结束】。下面分三部分说：做成了什么、卡在哪、下半年怎么改。
- **改后（有素材，演示版）**：1—6 月，部门完成 37 个项目，同比多 9 个；平均交付周期从 24 天降到 19 天（数据来自项目管理系统 1 月 1 日至 6 月 30 日记录）。下面分三部分说：做成了什么、卡在哪、下半年怎么改。
- **素材（用户提供，演示）**：37 个项目、同比多 9 个、平均交付 24→19 天、系统记录时间范围。
- **动了什么**：删万能开头和「显著成效」；结论先行；没有数据时用占位，不补数字。

**例 2 成绩段**

- **原稿**：我们持续优化业务流程，工作效率得到有效提升，团队协作能力显著增强。
- **改后（无素材，占位版）**：审批流程从【待补：原节点数】个节点压到【待补：现节点数】个，平均等待时间少了【待补：天数】；【待补：人数】名新同事做了【待补：次数】次业务培训，培训后测试均分从【待补：原分】提到【待补：现分】。
- **改后（有素材，演示版）**：审批流程从 7 个节点压到 4 个，平均等待时间少了 3 天；12 名新同事做了 4 次业务培训，培训后测试均分从 62 提到 78。
- **素材（用户提供，演示）**：7→4 个节点、等待 -3 天、12 人、4 次培训、均分 62→78。
- **动了什么**：每个形容词换成数字和动作；没有素材就写占位，不把「有效提升」改成编造的数字。

**例 3 问题与不足**

- **原稿**：工作中仍存在一些不足，如创新意识有待加强，精细化管理水平仍需提升。
- **改后（占位版）**：【待补：月份】有【待补：项目数】个项目因【待补：变更原因】延期；另【待补：人数】名同事离职，交接文档【待补：缺口】，【待补：时间】需要补齐。
- **有素材时**：把月份、项目数、变更原因、离职人数、交接缺口、补齐时间换成用户提供的事实；不写「有待加强」这类判断。
- **动了什么**：把「有待加强」换成可核对的事实和数量；写原因和影响；对己方不利的部分保留。

**例 4 下一步计划**

- **原稿**：下一步，我们将继续努力，持续发力，久久为功，推动各项工作再上新台阶。
- **改后（占位版）**：【待补：时间】前，把【待补：模板 / 文件】发到各组，由【待补：责任人】逐项确认；【待补：时间】完成【待补：事项】，负责人【待补：姓名】，【待补：时间】由我抽查。
- **有素材时**：每项都填动作、责任人、时间、验收 / 交付物；填不出的删除，不用空话替代。
- **动了什么**：删空表态；每个动作带时间、责任人、验收方式；「再上新台阶」是拔高，删掉后信息更清楚。

**例 5 述职报告**

- **原稿**：一年来，我认真履职尽责，积极完成领导交办的各项任务，取得了较好成绩，得到了领导和同事的认可。
- **改后（占位版）**：我负责的【待补：业务】今年新增【待补：数量】个合作方，带来【待补：金额】收入，占【待补：占比】；不足是【待补：具体问题】，明年【待补：改进动作】。
- **有素材时**：职责、结果、不足三样都用用户提供的事实；不足要指向自己的管理动作，不写「得到认可」。
- **动了什么**：职责 + 结果 + 不足，三样都有；删「认真履职」「得到认可」这类自我评价。

**例 6 情况报告**

- **原稿**：事故发生后，公司高度重视，第一时间启动应急响应，主要领导立即赶赴现场，举一反三，全面排查，确保类似事件不再发生。
- **改后（占位版）**：【待补：时间】，【待补：地点】发生【待补：事件】，【待补：后果】。【待补：直接原因】；【待补：责任主体】。已【待补：处置措施】，【待补：整改时限】前完成【待补：整改内容】，整改报告由【待补：部门】汇总。
- **有素材时**：时间、地点、后果、原因、责任、处置、整改时限七样，缺一样标待补；「高度重视 / 第一时间 / 举一反三」不替代事实。
- **动了什么**：程序化表态换成事实链；不编事故原因和责任，缺的标待补。

## 七、交付前自检（逐条回答是/否）

1. 第一段有没有给结果或结论？还是先铺背景、先感谢？
2. 每个数字有没有时间范围、口径、来源？同比 / 环比有没有说清？
3. 形容词后面有没有数字或事实？「显著 / 有效 / 大幅」还剩几个？
4. 问题有没有具体到现象、数据、原因、影响、责任？有没有只写「仍有不足」？
5. 下一步有没有动作、责任人、时间、验收 / 交付物？
6. 有没有把估计算成确定、把推测写进原因、把建议写成事实？
7. 报告有没有夹带请示？结语和文种对不对？
8. 述职有没有只表功、没写职责和不足？
9. 该保留的格式、法规原文、专有名词、涉密脱敏有没有处理？
10. 读完这一页，读者能不能说出「做成了什么、卡在哪、下一步做什么」？

## 八、与相邻文体的边界

- **报告 vs 请示**：报告是汇报 / 反映情况，不夹带请示；需要上级批复就另起「请示」，结语「妥否，请批示」。不能写成「以上报告，请批准」。
- **报告 vs 通知**：通知是向下布置任务、要求执行；报告是向上汇报，不带执行要求。
- **总结 vs 述职**：总结的對象是工作 / 单位 / 项目；述职的对象是自己这个岗位的职责履行。述职不能把单位成绩全写成个人成绩。
- **调研报告 vs 公众号文章**：调研要交代方法、样本、局限，结论可复核；公众号可以讲故事、有观点，不承担同样的举证责任。
- **情况报告 vs 新闻稿**：情况报告对上级负责，写原因、责任、整改；新闻稿对公众传播，侧重点和措辞不同，不能互相替代。
- **周报 vs 日报**：周报写进展、阻塞、需协调；日报写当天动作。不要把周报写成流水账，也不要把日报写成总结。
- **报告 vs 汇报 PPT**：PPT 提炼要点；完整数据、口径、过程留在报告正文。两份材料的数字必须一致。

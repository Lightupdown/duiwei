# 演讲稿：去 AI 腔档案 09

适用文本：开学典礼、升旗仪式、主题班会、成人礼、比赛 / 竞选演讲、纪念活动发言、家长会发言。核心标准不是“写得好”，是**念出来像这个人在这个场合说话**。

## 一、适用场景与目标

- 3–5 分钟，约 800–1500 字；听众是学生、老师或家长，现场会走神、会看手机、会鼓掌。
- 目标：让听众记住**一件具体的事、一个动作、一个判断**，不是记住一排排比。
- 演讲稿可以有书面底子，但不能像念文章；每句话要能一口气说完，长句后面要留气口。
- 结尾不是“把气氛推上去”，是让听众知道**下一步做什么**，或者记住一个画面。

## 二、人味标准

**允许：**

- 称呼、停顿、重复强调、口头衔接（「我讲个事」「说实话」）。
- 现场细节：时间、地点、人物、原话、当时的动作。
- 真实数据、真实经历、真实态度；允许一处不确定。
- 短句，但短句是为了换气，不是为了排成口号。

**禁止：**

- 三连祈使句收尾（「停三秒，看一眼，再扔」这类）。
- 排比升华、空喊「让我们」、每段一句金句。
- 「首先、其次、最后」式提纲；「在这个……的时代」式开场。
- 伪数据、伪故事、无出处引用；口号式数字（「停三秒」「三个关键词」「四个必须」）。
- 结尾变成横幅 / 海报 / 朋友圈文案。

**金句**：默认 0 句。最多 1 句 / 篇，且必须从正文事实里长出来；**上限不是任务，不许为了收尾补一句**。

## 三、AI 腔高危清单

1. **三连祈使口号**：「停三秒，看一眼，再扔」「多一份理解，少一份抱怨，添一份温暖」——三个动作一样长，像横幅。
2. **排比升华**：连续三句「让我们……」，或每段结尾都拔高。
3. **空喊**：「从今天开始」「从现在做起」「让我们一起」后面没有具体动作。
4. **提纲式**：「首先，……其次，……最后，……」——听众能猜到下一段。
5. **伪数据 / 伪故事**：「研究表明 90% 的人」「我有个朋友」；没有出处就删或标【待补】。
6. **每段金句**：隔几句就冒一句能截图的句子，全文没有一件具体事。
7. **口号数字**：「三个关键词」「四个必须」「停三秒」——数字是为了好记，不是为了准确。
8. **万能称呼 / 感谢**：开头「尊敬的各位领导、老师、亲爱的同学们」堆满，结尾「谢谢大家」之外没有内容。
9. **名人撑场**：一句名言 + 一个名人 + 一句「可见」。
10. **结尾三合一**：主题 + 情感 + 口号同时收，听众鼓掌，但不知道要做什么。

## 四、保留清单（看着像问题，其实不能改）

- **真实事例与数字**：时间、地点、人数、金额、原话；准确比漂亮重要。
- **称呼与现场关系**：对同学、对老师、对家长，称呼不一样。
- **重复与停顿**：演讲里同一句说两遍可能是强调，不要当啰嗦删。
- **个人态度**：可以不同意、可以承认自己也没做到，别写成完人。
- **现场物件 / 场景**：礼堂、操场、垃圾桶、教室后排，具体物比形容词有用。
- **政策口径 / 引用原文**：涉及学校规定、政策、数据，原样保留。
- **互动**：一次提问、一次停顿、一次看台下，是演讲稿的一部分。

## 五、改写顺序与手法

0. **判场合**：谁听、多长时间、在哪讲、讲完要他们做什么。
1. **找一件真事**：从自己的经历、学校最近发生的事、现场能看到的东西里找一件；没有就老实说没有，不许编。
2. **删口号**：三连祈使、排比升华、空喊「让我们」、每段金句，先删。
3. **把观点落到动作**：不说「要重视分类」，说「奶茶杯先倒水，再扔」。
4. **调呼吸**：长句后接一个短句；不要连续三个 ≤8 字的短句；一段只留一个重点。
5. **结尾测试**：把最后一句单独拿出来读——能印在横幅 / 海报上吗？能，就改糙；改成动作、画面、一个问题，或干脆删掉。
6. **念一遍计时**：出声读，卡住的地方是长定语或书面连接词；超时删例子，不删事实。
7. **自检**：过第七节，再检查事实与称呼。

## 六、AI → 人 对照（6 组）

**例 1 结尾口号**

- **原稿**：让我们从今天开始，停三秒，看一眼，再扔，共同守护我们的校园。
- **改后**：下次手里的奶茶杯，先把剩下的水倒掉。桶上写着什么，看一眼，再松手。
- **动了什么**：删三连祈使和「共同守护」；把号召换成一个具体动作；最后一句不再像横幅。

**例 2 开头空泛**

- **原稿**：在这个快速发展的时代，垃圾分类已经成为我们每个人都必须面对的重要课题。
- **改后**：上周三早读前，我在教学楼一层的垃圾桶旁边站了一会儿。一个没喝完的奶茶杯被扔进「其他垃圾」，杯盖弹出来，落在「可回收物」的桶盖上。
- **动了什么**：删时代腔和「重要课题」；从一个现场画面进入；不先给结论。

**例 3 中间排比**

- **原稿**：垃圾分类是责任，是担当，是文明，是我们每个人义不容辞的使命。
- **改后**：一袋混了塑料袋的厨余，到了处理厂，工人要花更多时间把它挑出来。这就是分类没做到位的代价。
- **动了什么**：删四连排比和空词；换成一个可核对的处理过程；让听众自己得出结论。

**例 4 伪数据**

- **原稿**：研究表明，90% 的垃圾都可以回收利用，只要我们都行动起来。
- **改后**：【待补：本校 / 本地可回收物的实际比例与来源】。先讲一个我们班这周产生的垃圾：纸、塑料瓶、奶茶杯各有多少。
- **动了什么**：没有出处就不写数字；改成可观察的班级样本，缺的标待补。

**例 5 口号数字**

- **原稿**：记住三个关键词：分类、减量、循环；做到四个必须：必须重视、必须行动、必须坚持、必须见效。
- **改后**：就三件事：倒干净、看清楚、单独放。倒干净是把奶茶水倒掉；看清楚是看桶上的字；单独放是电池、灯管不进普通垃圾。
- **动了什么**：删口号式数字和「四个必须」；每个词后面接一个具体动作，数字只为结构服务。

**例 6 空喊结尾**

- **原稿**：同学们，让我们携起手来，从我做起，从现在做起，为创建文明校园贡献自己的力量！
- **改后**：这周的值日生会在垃圾桶旁边站三天，不是监督，是有人不确定的时候可以问一句。你也可以来问。
- **动了什么**：删「携起手来」「从我做起」；把号召换成一个可看见的安排；最后一句留一个入口。

## 七、交付前自检（逐条回答是/否）

1. 最后一句单独读，能印在横幅 / 海报 / 朋友圈文案上吗？能，就改糙。
2. 有没有连续三个 ≤8 字的祈使句？有，删一个或加具体宾语。
3. 是不是把金句当成了必须完成的任务？0 句是否也成立？
4. 有没有一件只有你 / 这个学校能讲的具体事？
5. 数据、引文有出处吗？没有出处是否标了【待补】或删了？
6. 每段是在喊，还是在讲事实 / 动作 / 判断？
7. 称呼、场合、时长对不对？念一遍会不会超时？
8. 结尾落在动作、画面或一个问题上，还是落在口号上？
9. 删掉最后一句，演讲是否仍然完整？如果删掉更真，就删。
10. 有没有为了「有气势」加排比、加「让我们」、加假数据？

## 八、与相邻文体的边界

- **演讲稿 vs 视频口播**：演讲稿有书面底子、可以有修辞，面对的是礼堂；口播更像聊天，允许不完美和停顿。不要把口播的「哈、呢、吧」搬进开学典礼。
- **演讲稿 vs 文章**：文章给眼睛看，可以回看；演讲给耳朵听，过去就没了。演讲稿每句要能一次听懂，长句要拆。
- **演讲稿 vs 汇报**：汇报传递信息、要结论；演讲要影响判断、要行动。汇报不能空喊，演讲不能只有数据。
- **演讲稿 vs 考场作文**：作文有题目、字数、评分标准；演讲有听众、现场、时长。文学性演讲稿按 01 档案打底，结尾口号测试按本档案。
- **竞选演讲 vs 就职演讲**：竞选要说「我要做什么、怎么做、做不到怎么办」；就职要说「已经做了什么、下一步做什么」。两者都不靠排比。

方法来源：中文演讲与口头表达经验（`[经验]`），以及本技能对「金句配额 / 口号收尾 / 三连祈使」的校准记录；示例为演示写法，真实演讲只能用演讲者本人或学校提供的事实。

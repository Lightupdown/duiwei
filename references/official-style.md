# 官方文体一页判定表

> 用途：写 / 改官方评论、政务发布、公文、发言、报告时，先看这一页；详细依据在 `research/deep/gov-tone.md`、`research/deep/official-docs.md`，这里只留可执行的判断。

## 一、先判类型

1. **公文**（通知、通报、公告、通告、请示、报告、函）：格式与文种优先，准确第一。
2. **政务发布 / 公告**：面向公众，可把政策转译成生活场景，但信息必须准确。
3. **官方评论 / 社论 / 快评**：有立场、有号召，排比引用金句密度可以高于个人写作。
4. **官方发言 / 致辞 / 答问**：口语度高于公文，但分寸感和政策口径不能松。
5. **报告 / 总结**：见 `references/genres/08-报告与总结.md`；数据要带口径。

## 二、四测试：修辞该不该留

按顺序问，任一不过就进「空转」候选：

1. **可核验 / 可对账**：排比的每一项、引用的出处、金句的落点、对仗的两边，能不能对应到事实、数字、人物、机构、政策条款、时间地点？
2. **语境绑定**：把关键词换成同单位另一项工作，句子还通顺吗？换题照样成立 = 模板。
3. **位置功能**：它在开头定调、分论点领起、结尾收束，还是每段都来一句？结构位置上的可以留，密度失控的删到 1–2 处。
4. **可替换性**：删掉这句，论证会变弱、事实会缺一块吗？删了没损失 = 装饰。

口诀：**能对账、挪不动、在结构位置上、删了会疼**——四条都中才保留。

## 三、A 类：必须保留（看着像套话，其实是规范）

- **公文格式**：标题（发文机关 + 事由 + 文种）、主送机关、发文字号、成文日期、发文机关署名、印章、附件说明、抄送、印发机关和日期、页码；层次序数「一、」「（一）」「1.」「（1）」。
- **文种结语**：公告「特此公告」；告知性通知「特此通知」；执行类通知「以上通知，请认真贯彻执行」；报告「特此报告」；请示「妥否，请批示」；复函「此复」。不能混配。
- **文言词 / 专门用语 / 模糊语**：鉴于、业经、兹、现予、为荷、收悉、遵照、确有必要；「有关部门」「相关单位」「相当数量」用于概述时。执行责任、时间、地点必须具体。
- **政治规范表述**：中国式现代化、新质生产力、共同富裕、守正创新等，是规范提法，不是四字格堆砌。
- **有事实支撑的修辞**：可核验的排比、有出处的引用、有落点的金句、划政策边界的对仗。

## 四、B 类：可删可改（真套话 / AI 腔）

- **空转目的状语**：为…为…为…叠三层；背景超过一段。
- **空表态**：高度重视、认真落实、切实加强、确保取得实效；立即响应、举一反三（没有事实和处置）。
- **无信息客套**：感谢理解与支持（对内通知）、如有疑问请随时联系（没有联系人和电话）。
- **不可执行的下一步**：进一步加强、不断提升、持续优化（没有动作 / 责任人 / 时间 / 验收）。
- **意义拔高**：里程碑、新台阶、历史性突破——没有事实支撑就删。

## 五、C 类：不能出现（是差错，不是风格）

- 文种错配：内部停水用「公告」、报告夹带请示（「以上报告，请批准」）、执行类通知写「特此通知」。
- 过时要素：主题词、抄报、汉字成文日期（应阿拉伯数字）。
- 引文错、数据错、责任主体不明、时限不清。
- 法规原文、政治规范表述被改写或删改。

## 六、发布形态三档

| 形态 | 保留 | 删 / 改 |
| --- | --- | --- |
| 正式公文 | 全部格式要素、依据 + 目的 + 过渡语、分条、文种结语、署名、日期 | 只删空转叠加、空形容词、无信息客套 |
| 对外公告 / 政务发布 | 标题、正文、落款、日期、依据；政策转译成生活场景、可用「我们」 | 删空感谢；允许一句「敬请谅解」 |
| 群消息 / 邮件 | 时间、地点、动作、责任人、截止 | 删格式语、目的状语、客套 |

## 七、政务发布 → 对话体（改法，不是口语化）

- 换主语：「本部门」→「我们」；「群众」→「你 / 大家」。
- 换入口：先给与读者有关的结果，再给政策依据。
- 换语言：政策条文转译成生活场景（「开展专项整治」→「广场舞音响怎么调整更文明」）。
- 加原因：一句话说清为什么做，读者才知道跟自己什么关系。
- 留格式：发文机关、文号、法规原文、准确数字、正式称谓不动。
- 加温度：在通报里保留对当事人的关切，但不替代事实和处置。

## 八、报告 / 总结的额外三条

1. 数据必须有时间范围、同比 / 环比、来源、样本量；估算不能写成确定。
2. 问题要具体：现象 + 数据 + 原因 + 影响 + 责任；不能只写「仍有不足」。
3. 下一步要有动作、责任人、时间、验收；报告不夹带请示。

## 九、检测器怎么用

```bash
python3 scripts/ai_tell_lint.py --genre gov 评论.md
python3 scripts/ai_tell_lint.py --genre notice 通知.md
python3 scripts/ai_tell_lint.py --genre report 总结.md
```

- `gov`：官方对举、版式均匀只提示不扣分；政治话语 / 有支撑的修辞转人工四测试。
- `notice`：识别公文格式后，格式要素与文种结语不计分；官腔套话照常检出。
- `report`：报告 / 总结套话（万能开头、形容词成绩、问题虚化、空表态）照常检出。

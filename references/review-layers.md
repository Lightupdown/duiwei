# 第二层审稿：叙事类的四层审查（附议论卡 C）

`scripts/ai_tell_lint.py` 只查第一层：词、句式、句长、标点、段落节奏。它能把「贴脸」的 AI 腔抓出来，但有一类文本会让它给 0 分——词句都干净，细节也不缺，可人一读还是觉得「设计感太重、不像真的」。

**适用范围**：本文件的 L2–L4 与卡 A / 卡 B 面向**叙事类**（记叙文、散文、小说、公众号故事、口播故事）。议论类用下面的卡 C + 卡 B；通知 / 报告 / 聊天 / 文案等功能类只走保真门禁 + 各自文体档案的自检，不套本文件的叙事卡。

标准失败案例：`samples/hard-cases/01-ai-but-clean.raw.md`（原文，lint 0 分）+ `01-ai-but-clean.md`（逐条批注，卡 A 3/20、卡 B 4/10）。它不是来改的范文，是来校准眼睛的。

## 为什么脚本不够

脚本能测的东西：

- 词表命中、防御性句式、名言、时代腔；
- 句长 / 段长是否均匀；
- 口语标记密度、标点规整度。

脚本测不到的东西：

- 人物做的事前后矛盾（看摊又跟走）；
- 人物说出一句「格言」，不像本人；
- 细节每个都在服务主题，没有一个废的；
- 结构太顺，结局可预测；
- 结尾的「阳光落在手上」是作文腔意象。

这些问题的共同点：**它们靠语义和设计感，不靠词形。** 所以脚本必须配合人工审稿，不能反过来用分数替人做决定。

## 四层审稿

### L1 机器层（先跑，只做粗筛）

```bash
python3 scripts/ai_tell_lint.py --genre essay 稿子.md
```

看三样：风险分、命中项、人工复核提示。**0 分只说明没有明显表面痕迹，不说明过关。**

### L2 逻辑层（最先查，硬伤优先）

逐条回答：

1. **行动线**：把人物动作按顺序写成「谁—在哪—做什么—什么时间」。有没有同一时间出现在两处、做着互相冲突的事？
2. **视角**：叙述者这个年龄、这个位置，能不能看见 / 知道这些？（小孩能进现场吗？能听懂大人的话吗？）
3. **物件连续性**：门窗、工具、手机、钥匙、袋子，取出与放回有没有断。
4. **因果**：这个人为什么来、为什么走、为什么帮忙，站得住吗？
5. **时间线**：上午 / 下午 / 第二天，有没有和「几点、多长时间」打架。
6. **称呼关系**：谁管谁叫什么，前后一致吗。
7. **工序可信**：写到的操作，内行看了会不会摇头？（智能锁没电，常规解法是机械钥匙或应急供电，撬门缝对电子锁体无效。）不确定就老实写「我看不懂他在干什么」，不要编流程。
8. **事件阻力**：有没有失败、还价、怀疑、返工、拒绝？一次成功、全程配合、人人感动，多半是设计的。
9. **记忆误差**：人回忆会记错时间、名字、顺序。全篇精确无误，反而假。

一条不过，先改逻辑，不急着润色。

> 数据与口径检查（时间范围、同比 / 环比、来源、样本量）属于**报告 / 总结**，见 `references/genres/08-报告与总结.md`；不要拿它去套叙事文本。

### L3 人物与细节层

**A. 人物台词三问**（每句引号里的关键话都过）：

1. 这个人在这个场合，真的会这么说吗？
2. 能不能换成动作或沉默？
3. 有没有更普通、更具体、更技术性的说法？

**禁止**：让长辈 / 手艺人 / 老师说出格言（「哪有不坏的东西」「别用蛮力，找那个劲」）。格言是作者借人物的嘴说的，不是人物自己的话。

**台词测试**：把全文台词摘出来单独读一遍。能当文章标题、能当主题句、能拿去发朋友圈的，删掉或改糙。人物不能替作者说话。

**B. 细节负载审计**：把全文细节列成表。

| 细节 | 它在服务什么 | 判定 |
| --- | --- | --- |
| 旧毛巾 | 父亲节俭 / 手艺旧 | 功能 |
| 小铁盒里的铜屑 | 手艺的日常 | 功能 |
| 门垫卷角被脚背铺平 | 父亲细心 | 功能 |
| 阳光落在手上 | 收尾温度 | 功能 |

规则：

- **全部细节都在服务主题 = 过设计。** 诊断问题：每个细节都在干活吗？素材里有没有用不上的、不服务主题的细节可以留？**不设最低数量，也不要为了得分加闲笔。**
- **象征性细节全篇 ≤1 个**（亮痕、门垫、坏灯三选一，不要都留）。
- **回收率检查**：被写下的具体道具 / 名词，后面是不是都回收了？（纸→玻璃板、铜屑→铁盒、面条→吃面、灯→灯不亮。）**回收率过半就是设计。** 素材里本来就没再提的，不要硬补回收。
- 判断闲笔是否自然：写的时候是先想到「这个有用」，还是它本来就在素材里？前者是设计，后者才是闲笔。

**C. 表演式人味**：口癖成串、伪互动、伪自曝、童年崇拜（「我数他换了几样工具，数到一半就乱了」）、蹲下来摸一摸、抬头看天。看到就删。

**D. 情绪与意象**：情绪要落在动作和物件上，但一个动作只承担一个情绪；「阳光 / 月光 / 微风 / 亮痕 / 背影」这类意象，一篇最多一个，且不能放在结尾收束。

**E. 叙述者主体性**：叙述者有没有一句态度、羞耻、不耐烦、偏心？全篇像摄像头一样冷静记录，是 AI 的签名。人回忆会记错，也会有不想说的地方。

### L4 结构层

1. **可预测性**：读完开头，结局是不是已经能猜到？二元对立（智能 vs 手艺、城市 vs 乡村、老师 vs 学生）不要一方完胜。
2. **闭环**：结尾是不是硬回到开头、硬点主题、硬给一句「道理」？
3. **顿悟**：有没有「我终于明白了 / 那一刻我懂了 / 原来……」？
4. **信息分配**：是不是每段都在推进主题，没有一段真正「没用」？
5. **反模板**：让「对的」那一方输一次、让主角判断错一次、或让结尾留一个没解决的东西。
6. **结尾三合一检查**：主题 + 情感 + 意象是不是在最后一段同时闭合（记型号 + 递锁 + 阳光）？是就删一个。留不留悬空由文体决定，不强制。
7. **道具成对回收**：开头的道具是不是都在结尾被收回来了？回收得越整齐，越像设计。

## 两张评分卡：真实感 + 文笔（叙事类）

去 AI 味不是把文章改干净就行。**只盯第一张卡，会写出一篇「没有 AI 腔、但干瘪平庸」的流水账；只盯第二张卡，会写出一篇「漂亮但假」的作文。两张卡都过，才算完成。**

### 卡 A｜真实感（10 项，每项 0–2 分，满分 20；仅叙事类）

未过线：**从零写作 <14 分不能交付**；14–15 分看文体；≥16 分通过。**改写模式见下方 N/A 规则。**

| # | 项目 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- | --- |
| 1 | 逻辑自洽 | 有硬伤 | 一处小别扭 | 行动线、时间、物件都对 |
| 2 | 工序可信 | 内行会摇头 | 大致像，细节模糊 | 经得起内行复述或老实留白 |
| 3 | 台词非格言 | 人物在替主题发言 | 部分像本人 | 像本人说话，能换成动作 |
| 4 | 有废笔（不设数量） | 每个细节都在干活 / 为得分硬凑 | 有一处但显得刻意 | 素材自带、不服务主题、不刻意 |
| 5 | 叙述者有态度 | 摄像头式冷静 | 有一处情绪 | 有偏好、羞耻或偏心 |
| 6 | 有记忆误差 | 全篇精确无误 | 一处「大概」 | 有真实的记错 / 不确定 |
| 7 | 事件有阻力 | 一次成功、人人配合 | 有一点波折 | 有失败、还价或怀疑 |
| 8 | 细节独属 | 换个人也能用 | 一半可替换 | 只有当事人知道 |
| 9 | 结构有悬空 | 完全闭环 | 有一处没交代 | 留了真正未解决的东西（按文体） |
| 10 | 意象不复用 | 意象成对回收 | 一处回收 | 意象只用一次，不回收 |

> **改写模式下的 N/A（重要）**：用户拿自己的稿子来改时，原文里本来没有的项——记忆误差、事件阻力、结构悬空、闲笔——标 **N/A**，不计入分母，也不要在改写时补造。
>
> - **从零写作**：卡 A <14 不能交付。
> - **改写**：卡 A 只作诊断，不设交付门槛；交付以「不新增事实 + L2–L4 无硬伤 + 卡 B 过线」为准。用户要求逐项评分时，用 N/A 折算分母。
> - 卡 C 同理：原文没有反方 / 方法时，相关项标 N/A；不要为了凑分编一个反驳。

### 卡 B｜文笔与完成度（5 项，每项 0–2 分，满分 10；叙事 / 议论通用）

未过线：**<7 不能交付**；7 分须打磨后复评；8–9 分可用；10 分是目标。

| # | 项目 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- | --- |
| 1 | 用词贴切 | 空泛、堆形容词 | 大体准确 | 动词、名词下得准，有表现力 |
| 2 | 句式与节奏 | 均匀、念着平 | 有变化 | 长短错落，节奏跟着情绪走 |
| 3 | 意象 / 比喻 | 陈词滥调或没有 | 有一处贴切 | 至少一处新鲜、承担意义的比喻 |
| 4 | 细节有意味 | 全是功能或全是闲笔 | 有细节但不突出 | 细节既具体又有余味，不解释 |
| 5 | 结尾 / 余味 | 靠格言、升华、阳光收束 | 停在动作，略平 | 停在具体处，留得住，不喊口号 |

### 卡 C｜议论类（6 项，每项 0–2 分，满分 12）

未过线：**<8 不能交付**；8–9 分打磨后复评；≥10 可用。与卡 B 一起用。

| # | 项目 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- | --- |
| 1 | 扣题 | 全文可套任何题目 | 提到题目词但没展开 | 标题 / 开头 / 段首 / 结尾都扣核心词 |
| 2 | 论点链 | 观点散、跳步 | 有主线但有一处断 | 每段回答中心问题，推进清楚 |
| 3 | 论据真实 | 伪数据、无出处 | 有例子但来源模糊 | 例子、数据、引文可核对 |
| 4 | 分析 | 以例代议、只贴标签 | 有分析但浅 | 例子后有推理，不只说「可见」 |
| 5 | 反驳 / 边界 | 树稻草人 | 提到反方但没回应 | 处理真实反例，说清适用边界 |
| 6 | 结论 | 空降升华 | 重复前文 | 从正文长出来，不喊口号 |

### 卡怎么用

- 先判档位（叙事 / 议论 / 功能），再选卡：叙事 A+B，议论 C+B，功能类不打卡。
- 打分后决定改哪里：A 低改设计与逻辑，B 低改语言与收束，C 低改论证与论据。
- **A 过 B 不过，是「作文腔」；B 过 A 不过，是「漂亮假文」；C 不过，是「没有论证」。**
- 打分不解释等于没打：每项写一句理由。

## 硬门禁

- L2 有硬伤：**不交付**，先改逻辑。
- L3 细节全部有功能、人物台词格言化：**重写这一段**，不要只换词。
- L4 结局可预测且闭环：**改结构**，不要靠删金句糊弄。
- **从零写作**：叙事类卡 A <14 不能交付；议论类卡 C <8 不能交付；卡 B <7 一律不能交付（7 分打磨后复评）。
- **改写他人稿**：卡 A / C 作诊断（缺项 N/A）；交付以「不新增事实 + L2–L4 无硬伤 + 卡 B ≥7」为准，不得为了凑卡编细节。
- 功能类：不打卡；走保真门禁 + 该文体档案第七节自检。
- **最小干预 / 校对 / 错别字级 / 只润色**：不打卡（A/B/C 都不打），只走保真门禁 + `07-润色与改稿.md`；不得为了卡 B 改写句子或加修辞。
- 改完通读：还有没有一句是「作者替人物说的」？

## 过度纠偏：去 AI 味不是写差

改完要同时防两种失败：

- **假**：设计感、格言、闭环、堆意象——卡 A 管。
- **干**：句子全短、全是大白话、没有比喻、没有节奏、没有一句有味道的话、细节全变成功能交代——卡 B 管。

如果为了「不像 AI」把文章改得没有比喻、没有态度、每句都在交代事实，那是另一种失败，叫流水账。**文笔不是辞藻，是准确、有表现力、节奏对、细节有意味。** 卡 B 就是防这个的。

## 冷读：挑刺读者七问

自己审自己容易护短。交付前换身份，只当读者：

1. 哪一句是我为了主题硬塞进去的？
2. 哪个人物说话像作者在发言？
3. 哪个细节我在写的时候先想到「这个有用」？
4. 结尾是不是我早就想好的？
5. 删掉哪一段，文章反而更真？
6. 哪一句读起来干瘪、像在交代事实？
7. 哪里本来该有一个好比喻 / 一次停顿 / 一个准确的动词，我没写出来？

前五问答得出来，回去改设计；后两问答得出来，回去补文笔。

## 与生成流程的配合

- **写**：先写，一次成型不算完成。叙事类过 L2–L4 再跑 L1；议论类用卡 C + 卡 B；功能类按文体档案自检 + 保真门禁。
- **改**：先跑 L1 出命中清单，再按档位审；L2 有硬伤时，不做句子级润色。
- **提素材**：`python3 scripts/review_extract.py 稿子.md` 会把段落首末句、全部台词、数字、时间词、意象候选、结尾三段抽出来，省得来回翻原文。
- **复杂稿**（叙事作文、议论长文、演讲稿按主干判）：可以起一个独立的 critic 子代理，只给它稿子和本文件，让它按对应卡打分并挑刺，再接回来改。自己审自己会护短。
- **报告**：交付时写明对应档位的得分（叙事 A/B、议论 C/B，功能类写按档案自检）与三处改动，不只报 lint 分数。

## 什么时候算改完（防止无限打磨）

- **从零写作**：叙事类 A ≥14、B ≥7；议论类 C ≥8、B ≥7；功能类按档案自检全部通过。
- **改写他人稿**：卡 A / C 只作诊断（缺项 N/A），卡 B ≥7；交付以「不新增事实 + 没有 L2 硬伤」为准。不要为了卡 A 分数去补原文没有的记忆误差 / 阻力 / 悬空。
- **有条件时**至少一轮独立盲评认为「能交付」，并且它提的高优先级意见已经处理；没有独立评审代理时，用七问自审，并在交付说明里注明「未独立复评」，不能假装有。
- 没有 L2 硬伤，也没有一句「作者替人物说的」。
- 再读一遍，找不到为改而改的痕迹。继续改会把自然感磨掉，就停。

**满分不是目标。** A 15–17、B 9 是正常的好作文区间；A 20/20 往往意味着又写回设计了。宁可留一处口味上的不完美，也不要把它磨成另一篇作文模板。

# 样本说明

这些样本用来校准和测试 `scripts/ai_tell_lint.py`，也作为「AI 稿 → 人话稿」的最小对照。分数会随脚本阈值调整变化。

| 文件 | 内容 | 当前体检分 |
| --- | --- | --- |
| `01-ai-koubo.md` | 典型 AI 口播稿：防御性句式、第一/第二/第三、客服结尾、金句密度高 | 71 / 100（AI 味重） |
| `02-human-koubo.md` | 同一主题的人话改写：具体细节、停顿、语气词、改口、不完美结尾 | 0 / 100（自然） |
| `03-ai-copy.md` | 典型 AI 书面文案：随着…发展、进行+动词、研究表明、打造闭环 | 51 / 100（明显 AI 味） |
| `04-human-copy.md` | 同主题人话改写：公开课细节、短句、留白、具体动作 | 0 / 100（自然） |
| `05-ai-essay.md` | 典型 AI 作文：时代腔开场、名言撑场、排比升华、看似…却… | 70 / 100（AI 味重） |
| `06-human-essay.md` | 同主题人写作文：具体观察、克制叙述、不升华，全程书面语 | 4 / 100（自然） |
| `07-excellent-essay.md` | 优秀人写散文：具体细节、克制情绪、无口语词，检验不误伤 | 0 / 100（自然） |
| `08-official-notice.md` | 规范通知：格式完整、结论先行、无套话，检验不误伤 | 0 / 100（自然） |
| `09-essay-zhineng.md` | 793 字正样本（智能主题）；lint 0 分且无第二层提示，两轮盲评均判能交付 | 0 / 100（自然） |
| `10-ai-report.md` | 典型 AI 工作总结：万能开头、形容词成绩、问题虚化、空表态 | 36 / 100（轻微 AI 味） |
| `11-human-report.md` | 人写工作总结：数据带口径、问题具体、下一步可执行 | 0 / 100（自然） |

> 这些样本都进了 `scripts/selftest.py`，改脚本后跑自检做回归。
> 07 / 08 专门用来查「误伤」：优秀散文和规范公文必须判自然；08 还用于 `--genre notice` 的公文格式保护测试。
> `hard-cases/` 是坏样本库：`01-ai-but-clean.raw.md` 给脚本跑（lint 0 分），`01-ai-but-clean.md` 是逐条批注 + A/B 两张卡打分。写作文前先看一遍。
> `09-essay-zhineng.md` + `.notes.md` 是正样本：同样 lint 0 分、无第二层提示，用来和坏样本对照，验证「脚本分不出、第二层才分得出」。
> 字数少于 150 的短文案分数容易被低估，以命中项和建议为主。

跑法：

```bash
python3 scripts/ai_tell_lint.py samples/01-ai-koubo.md samples/02-human-koubo.md
```

新增样本时注意：

- 放真实感强的稿子，不要为了凑特征写成漫画式 AI 腔，否则会误导阈值。
- 每加一个样本，在表里补一行分数；分数变化需要说明是样本变了还是脚本调了。

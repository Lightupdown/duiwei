# 坏样本 01｜《智能锁没电那天》

> 用途：这是「lint 0 分、但人一读仍觉得有 AI 味」的标准失败案例。不是范文，是校准眼睛用的。写作文 / 改写时先看它的批注，再动手。
>
> 原文（用于跑 lint）：`01-ai-but-clean.raw.md`。
>
> 机器层结果：`ai_tell_lint.py --genre essay` 风险分 **0 / 100（自然）**，但会提示「作文腔意象 / 人物格言句 / 无阻力 / 过度洁净」。人工审稿：**卡 A 3 / 20，卡 B 4 / 10**，两张都不过。
>
> 教训：脚本 0 分 ≠ 过关。问题在逻辑、工序、人物台词、细节负载、结构闭环、语言过于均匀六层。

## 原文

标题：智能锁没电那天

我爸是开锁的，在小区南门摆一张折叠桌。桌上放一台配钥匙的机器，一盒大小不一的坯子，一块擦得发黑的旧毛巾。他那个军绿色工具包拉链坏了一边，用铁丝拧着。这几年，楼道里换智能锁的人越来越多，他的手艺就淡了。有时一上午等不到一个人，他就坐着磨一把旧弹子锁，磨完拆开，再装回去。

配钥匙的机器转起来声音很尖，铜屑落在抽屉里，攒多了他倒进一个小铁盒。

我很小的时候，他带我去城西的旧楼，帮人开一只卡住的抽屉。他蹲着，手很稳。我在旁边数他换了几样工具，数到一半就乱了。

摊子头顶是小区新换的广告牌，「智能生活，一键开启」几个字，晚上会亮。上个月的一天，隔壁楼的张奶奶来摊上，手里攥着一个装了药的塑料袋，说家里那把智能锁没电了，人被关在门外。我爸收好工具，让我看摊。我那天没课，跟着去了。

张奶奶住六楼，门锁黑着屏，手机上的App停在「连接中」。她儿子在外地，临时密码发不过来。我爸蹲下来，先看锁孔，又从包里摸出一片薄铁片和一根弯钩，贴着门缝试。张奶奶在旁边说，这锁花了两千多，卖锁的说以后不用带钥匙。我爸没接话，手上的东西换了三次。楼道里的声控灯灭了，我跺了一脚，灯又亮。大概七八分钟，锁里「咔」了一声。

门开了。张奶奶站在门口，先没进去，回头说，我以为这锁一辈子不用管。屋里飘出煮面条的味道，电视机开着，在重播午间新闻。我爸让她找出一把备用机械钥匙，挂在门后的钉子上，又拿她的手机教她怎么用充电宝临时供电。锁的型号记在一张纸上，折了两折。张奶奶要给钱，他收了二十，说下次路过帮她换电池。她家门垫上印着「出入平安」，角卷起来一块，我爸用脚背把它铺平。

下楼时他顺手把楼道里那盏不亮的灯按了按，没亮。张奶奶送到楼梯口，说下次来家里吃面。

回去的路上我问他，都换成智能锁了，你这行是不是快没了。他把工具一件件擦干净，放回包里，薄铁片上多了一道磨出来的亮痕。他没抬头，说，哪有不坏的东西。

第二天早上，他把那张记着智能锁型号的纸压在摊子的玻璃板下面，又摆出配钥匙的机器。本子上已经记了七八个牌子，有的字他不认识，就照着描下来。阳光挪过来，落在他手上。他让我坐过去，把一把旧锁递给我，说，你试试，别用蛮力，找那个劲。

## 逐条批注

### 逻辑层（硬伤）

- **「我爸收好工具，让我看摊。我那天没课，跟着去了。」**
  让他看摊，人却跟走了。前后矛盾。
  改法一（保摊）：把抽屉锁了，说反正一上午没人，跟他走。
  改法二（托人）：隔壁修鞋的婶子帮忙盯着。
  改法三（删掉）：删「让我看摊」，改成「说去去就回」。

- **「我那天没课」**：交代太含糊。改成「下午没课」或「那天下午正好空着」更可信。

- **「下楼时他顺手把楼道里那盏不亮的灯按了按，没亮。」**
  行为本身没问题，但它是「父亲手巧心细」的功能性细节，和主题呼应得太准——不是生活里顺手发生的事，是作者安排的事。

- **「先看锁孔，摸出薄铁片和弯钩，贴着门缝试」：工序不可信。** 智能锁没电的常规解法是机械钥匙或应急供电，撬门缝对电子锁体无效，这是编出来的行业流程。内行一读就出戏。
- **全篇零阻力**：一次开成、不还价、张奶奶不怀疑、父亲每一步都顺利。写不出失败的事件，多半是设计出来的。
- **零记忆误差**：叙述者记得每一句话、每个动作、花了七八分钟。人回忆会记错，全篇精确无误反而假。

### 人物台词层（最重的 AI 味）

- **「别用蛮力，找那个劲。」**
  格言体。开锁匠不会用「那个劲」三个字打发徒弟——他说不出「哪个劲」，说明这句是作者替他说的人生道理。
  改法：「先往回带一点，听见里面响再动。」（操作）
  或：「手别攥死，感觉卡住了就往回退。」（手艺）

- **「哪有不坏的东西。」**
  又一句格言。前文没建立他说这种话的习惯，突然来一句哲理，像作文模板里的「爷爷说」。
  改法：「电池该换了。上回那家也是。」（技术性、日常、泼冷水）
  或者干脆不接话，只写他擦工具的动作。

- **张奶奶「我以为这锁一辈子不用管。」**
  自然度尚可，保留一句；但它同时替主题说了话（技术承诺的虚妄），属于「半句人物、半句作者」。如果整篇只有这一句这样的台词，可以留；多一句就成作者代言。

- **「下次路过帮她换电池」**：善意精确到工序，等于给父亲发道德分。可以留，但最好补一句代价（比如他忘了，或者那家后来没再找他）。

### 细节层（过设计）

| 细节 | 服务什么 | 判定 |
| --- | --- | --- |
| 旧毛巾、军绿工具包、铁丝拉链 | 手艺的旧与节俭 | 功能，偏多 |
| 配钥匙机器声、铜屑、小铁盒 | 手艺的日常质感 | 功能，好 |
| 小时候数工具、数到一半乱了 | 童年崇拜、衬托父亲厉害 | 套路细节，删或换 |
| 门垫卷角、脚背铺平 | 父亲细心 | 功能，好但太巧 |
| 薄铁片上的亮痕 | 手艺的磨损与尊严 | 象征，占了一个名额 |
| 阳光挪过来、落在手上 | 收尾的温暖 | 作文腔意象，删 |
| 坏灯按了没亮 | 父亲手巧 | 功能，可删 |

规则：**至少一处无用闲笔**（踢易拉罐、隔壁推车、电视里具体在放什么），**象征性细节 ≤1**。

**回收率检查**：纸→玻璃板、铜屑→铁盒、面条→吃面、灯灭→灯不亮、铁片→亮痕，道具几乎全部成对回收，回收率过高就是设计。**铁盒被写下后再也不出现**，是另一种设计痕迹（写了就丢，为质感服务）。真人写作会有一两成细节写了就丢，也不回收。

**密度峰值**：「门垫上印着『出入平安』，角卷起来一块，我爸用脚背把它铺平。」一句叠三重设计：文字反讽 + 做旧 + 不经意的温柔。单看是好句子，放在全篇功能化细节里，反而暴露设计密度过高。

### 结构层

- **闭环太顺**：智能锁坏 → 老手艺救场 → 父亲说一句淡然的话 → 第二天教我。二元对立（智能失灵 / 手艺可靠）一方完胜，结局完全可预测。
- **道具成对回收**：纸→玻璃板，铜屑→铁盒，面条→吃面，灯→灯不亮，铁片→亮痕。收得太齐，像设计好的。
- **结尾三合一**：记型号（主题）+ 递锁（传承）+ 阳光（意象）同时闭合，一处没留空。
- **改法**：让智能赢一次（父亲也用手机、承认新锁方便），或让主角判断错一次，或结尾留一个没解决的东西（比如那盏灯一直没修、张奶奶后来再没来）。

## 语言层（干净过头也是签名）

- **句长挤在 10–25 字**，全篇无破折号、省略号、感叹号，问号也没有。干净过头，本身就是一种腔。
- **叙述者零主体性**：没有一句态度、羞耻、不耐烦或偏心；像摄像头记录。
- **全篇没有一处记忆不确定**：时间、对话、动作都精确，人回忆不会这样。

## 保留清单（这几处像人，重写时不要动）

- 「有的字他不认识，就照着描下来」——唯一带缺陷、不解释的细节，作者没美化父亲。
- 「用铁丝拧着」——旧而不体面的细节，没有抒情。
- 第二段一句成段——节奏是个人化的。
- 「我跺了一脚，灯又亮」——现场反应，不承担主题。
- 两次「没接话」——沉默比台词真实。
- 结尾停在动作，没有「我终于明白了」——这一点是对的，只是动作选得太工整。

> 注意：卡 B 不是骂它文笔烂。它能读，问题在于每个词都在安全区里，没有一处真正新鲜、准确到只有作者写得出的表达。**A 卡不过 + B 卡不过 = 设计感重的作文腔。**

## 为什么 lint 给 0 分

词表里没有命中；防御性句式没有；名言没有；句长与段落有变化；具体数字、物件、引号多，拿到了加分。于是表面分被抵到 0。
它测不到「看摊」的矛盾、「哪有不坏的东西」的格言感、「每个细节都在干活」的过设计。这就是为什么必须有第二层审稿（`references/review-layers.md`）。
